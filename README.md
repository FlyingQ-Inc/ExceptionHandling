# Exception Handling | C# Coursework

## Overview
A C# programming exercise focused on handling runtime errors and improving application reliability.

The project provides a place to examine exception-handling patterns in actual course code rather than relying on conceptual descriptions alone.

## Technical focus
- Recognizing conditions that can cause runtime exceptions
- Using C# `try` and `catch` constructs
- Separating normal program flow from error handling
- Providing understandable feedback when an operation fails

Refer to the included source files for the exact exception cases handled.

## Running the project
Open the solution or project in Visual Studio with a compatible .NET SDK and, for Windows Forms projects, the .NET desktop development workload. Build and run the project, then exercise the applicable input and error scenarios.

## Portfolio relevance
Potential supporting evidence of defensive programming and software reliability for Network Engineering. Exception handling alone does not establish formal security testing or test-driven development.
